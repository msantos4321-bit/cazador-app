# Cazador de Ofertas · app

App web (instalable en Android y iPhone) del Cazador de Ofertas. Solo contiene las pantallas: los datos viven en Supabase con reglas de seguridad por persona, y la clave que aparece en `config.js` es la publicable (hecha para ir en el navegador). El código del recolector y los datos están en un repositorio privado aparte.
